# 3D models

Kenney CC0 kits, downloaded manually and committed here as `.glb`:

- `desk.glb` — from Kenney "Furniture Kit"
- `character.glb` — from Kenney "Mini Characters"
- `floor.glb` — from Kenney "City Kit" (a plain plate is fine)

Source: https://kenney.nl/assets — all CC0, no attribution required.

If a file is missing the scene renders a plain box in its place rather than
failing, so the console still works before the assets are added.
